# Power BI E-Commerce Sales Dashboard

## 📌 Project Overview
This project is an interactive Power BI dashboard designed to analyze E-commerce sales data and provide actionable business insights.

## 📊 Key Features
- Interactive KPIs: Sales, Profit, Quantity & AOV
- Drill-down analysis using slicers and filters
- Sales analysis by State, Category, Month & Payment Mode
- Multiple visualizations: Bar chart, Donut chart, Line chart, Clustered chart

## 🛠 Tools & Technologies
- Power BI Desktop
- DAX
- Data Modeling

## 📈 Insights Generated
- Identified top-performing states and product categories
- Monthly profit trends and seasonal patterns
- Customer-wise sales contribution
